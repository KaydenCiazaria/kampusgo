event id, so Compose can tell evt-01 from evt-02 after a redraw. A tap must open another screen.

4.  The list, one block at a time 
5.1  Empty list 
Where: a new file EventList.kt, in the same folder as MainActivity. Kind: File. 
LazyColumn only builds the rows that are on screen. A Column of eight texts would build all of them. If the list 
is empty, LazyColumn is not used. The words No events are the empty state. onEventClick receives the id of 
the tapped row. This function does not build an Intent.
